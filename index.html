VilasSoft

Na VilasSoft, desenvolvemos soluções digitais sob medida para pequenas e médias empresas que querem crescer com presença online, eficiência e inovação. Atuamos com foco na criação de sites profissionais, sistemas sob demanda que simplificam processos e geram resultados reais. Nosso compromisso é unir tecnologia, design e estratégia para entregar projetos ágeis, responsivos e prontos para transformar sua presença digital.

Tecnologias que usamos

React

React é uma framework para criação de aplicações webs, usada para criar aplicações SPAS(Single Page Applications)

JavaScript

JavaScript é uma linguagem que adiciona interatividade aos sites e pode ser usada no back-end com Node.js.

HTML

HTML estrutura páginas da web com textos, imagens e links.

CSS

CSS estiliza páginas da web, definindo cores, fontes e layouts.

TypeScript

Superset do JavaScript com tipagem estática para códigos mais seguros.

Git

Sistema de controle de versão distribuído para gerenciar código.

Studio Cleide - Clinica de estética

O Studio Cleide é uma clínica de estética especializada em micropigmentação e despigmentação, que também oferece uma variedade de outros serviços voltados ao cuidado e à beleza. Desenvolvi o site institucional com foco em design moderno e experiência do usuário (UI/UX), aplicando os principais conceitos de landing pages otimizadas para conversão e SEO (otimização para mecanismos de busca). O resultado foi uma presença digital profissional e atrativa, que elevou o posicionamento online da marca. O site atualmente aparece entre os primeiros resultados nas pesquisas da categoria principal na região, o que ampliou o alcance e a credibilidade da clínica. Além disso, o novo layout e o catálogo digital mais completo e organizado permitiram que os clientes conhecessem melhor os serviços, transmitindo mais confiança e sofisticação — valores essenciais para o mercado da estética.

Landing Page: Cafeteria

Este é um protótipo de cafeteria desenvolvido com HTML, CSS e JavaScript. O JavaScript é utilizado para manipulação do DOM, permitindo que, ao clicar no botão "Endereço", a localidade da cafeteria seja exibida dinamicamente. O projeto foca em proporcionar uma interação simples e intuitiva para o usuário, com design responsivo e funcionalidade eficiente.
